# Mathical — финансовый симулятор

Исходный код учебного симулятора личных финансов. В репозитории нет банковских выписок и персональных документов.

## Как открыть

Скачай папку проекта и открой `index.html` в браузере. Установка не нужна. Страницы связаны между собой обычными ссылками, а план и настройки хранятся в браузере и общие для всех страниц.

## Страницы сайта

- `index.html` — главная: описание и живой пример расчёта.
- `plan.html` — план: доходы, расходы, цель, кредит, срок и допущения модели.
- `results.html` — результаты: график капитала, бюджет, цель, диапазон, финансовое здоровье, кредит.
- `compare.html` — сравнение: жизненные решения, до трёх сохранённых вариантов, таблица по годам, экспорт CSV и картинки.
- `inflation.html` — официальный показатель и выбор инфляции для плана.
- `method.html` — как считается: формулы и допущения.
- `settings.html` — настройки сайта: тема, анимации, суммы по умолчанию, коридор на графике, экспорт/импорт данных и сброс.

## Файлы проекта

- `css/site.css` — общий стиль и анимации.
- `js/store.js` — общее хранилище (план, варианты, настройки).
- `js/ui.js` — шапка, тема, переходы между страницами, анимации чисел и графика.
- `js/home.js`, `js/plan.js`, `js/results.js`, `js/compare.js`, `js/settings.js` — логика страниц.
- `engine.js` — расчётная модель, `engine.test.mjs` — её проверки.
- `format.js` — деньги, проценты и сроки, `chart.js` — график капитала (`chart.test.mjs` — проверки).
- `documents/Проверка основы модели.md` — контрольные формулы и ожидаемые результаты.

## Сборка и проверки

Нужен Node.js. В папке проекта выполните:

```powershell
node --test engine.test.mjs chart.test.mjs
node build.mjs
```

`node build.mjs` обновляет версии CSS и JavaScript в страницах, чтобы браузер загружал актуальные файлы, и создаёт папку `dist/` с семью автономными страницами: стили, скрипты и шрифт встроены внутрь каждой. Папку `dist` можно целиком выложить на любой хостинг.

Модель учебная: параметры и сценарии условны, результат не является финансовым прогнозом.

Все расчёты выполняются в браузере.

Запас средств считается по жилью и необходимой части остальных уже введённых расходов. Классификация не добавляет расходы повторно; расчёт использует накопления после разовой траты и расходы на старте без будущих доходов и инфляции.

## Цель и кредит

Для цели рассчитывается постоянный ежемесячный взнос с учётом заданных инфляции и доходности. Предполагается, что начальные накопления за вычетом разовой траты направлены на цель; будущие изменения бюджета и сценарии в этом расчёте не учитываются.

Для действующего кредита рассчитываются равные платежи по остатку долга, годовой ставке и оставшемуся сроку. Платёж учитывается в бюджете до конца срока. Долг не прибавляется к капиталу и не вычитается из него; комиссии, страховка, переменная ставка и досрочные платежи не учитываются. Фактический график банка может отличаться. [Кредитный калькулятор Банка России](https://fincult.info/calc/dosrochnoe-pogashenie-kredita/).

Шрифт Onest включён в проект для работы без сети; условия его использования находятся в `Onest-LICENSE.txt`. Сборка `dist/` встраивает шрифт внутрь каждой страницы.
