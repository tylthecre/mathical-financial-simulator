# Mathical — финансовый симулятор

Исходный код учебного симулятора личных финансов. В репозитории нет банковских выписок и персональных документов.

## Как открыть

- На компьютере скачайте `Mathical.html` и откройте его браузером. Установка не нужна.
- В GitHub на телефоне можно просматривать исходники по файлам. Для запуска приложения скачайте `Mathical.html` и откройте его браузером.

## Файлы проекта

- `index.html`, `styles.css`, `app.js` — интерфейс и оформление.
- `engine.js` — расчётная модель.
- `engine.test.mjs` — проверки модели.
- `Mathical.html` — автономная версия приложения для переноса одним файлом.
- `documents/Проверка основы модели.md` — контрольные формулы и ожидаемые результаты.

## Сборка и проверки

Нужен Node.js. В папке проекта выполните:

```powershell
node --test engine.test.mjs
node build.mjs
```

Модель учебная: параметры и сценарии условны, результат не является финансовым прогнозом.

## Как устроен код

- `index.html` и `styles.css` — структура и оформление.
- `engine.js` — финансовые расчёты и сценарии.
- `format.js` — деньги, проценты и сроки.
- `chart.js` — график капитала.
- `app.js` — управление, ввод и сохранение параметров.

Все расчёты выполняются в браузере; `Mathical.html` содержит приложение целиком.

Запас средств считается по жилью и необходимой части остальных уже введённых расходов. Классификация не добавляет расходы повторно; расчёт использует накопления после разовой траты и расходы на старте без будущих доходов и инфляции.

## Цель и кредит

Для цели рассчитывается постоянный ежемесячный взнос с учётом заданных инфляции и доходности. Предполагается, что начальные накопления за вычетом разовой траты направлены на цель; будущие изменения бюджета и сценарии в этом расчёте не учитываются.

Для действующего кредита рассчитываются равные платежи по остатку долга, годовой ставке и оставшемуся сроку. Платёж учитывается в бюджете до конца срока. Долг не прибавляется к капиталу и не вычитается из него; комиссии, страховка, переменная ставка и досрочные платежи не учитываются. Фактический график банка может отличаться.
