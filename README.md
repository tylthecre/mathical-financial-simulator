# Mathical — финансовый симулятор

Исходный код учебного симулятора личных финансов. В репозитории нет банковских выписок и персональных документов.

## Как открыть

- На компьютере скачайте `Mathical.html` и откройте его браузером. Установка не нужна.
- В GitHub на телефоне можно просматривать исходники по файлам. Для запуска приложения скачайте `Mathical.html` и откройте его браузером.

## Файлы проекта

- `index.html`, `styles.css`, `app.js` — интерфейс и оформление.
- `engine.js` — расчётная модель.
- `engine.test.mjs` — проверки модели.
- `mathical-full-site.html` — весь сайт одним HTML-файлом: стили и JavaScript встроены; скачайте и откройте браузером.
- `Mathical.html` — та же автономная версия приложения.
- `documents/Проверка основы модели.md` — контрольные формулы и ожидаемые результаты.

## Сборка и проверки

Нужен Node.js. В папке проекта выполните:

```powershell
node --test engine.test.mjs
node build.mjs
```

Модель учебная: параметры и сценарии условны, результат не является финансовым прогнозом.
