# Mathical — финансовый симулятор

Учебная модель личного бюджета, накоплений и финансовых целей. Все расчёты выполняются в браузере. В репозитории нет банковских выписок и персональных документов.

## Как открыть

Опубликованный сайт: https://tylthecre.github.io/mathical-financial-simulator/.

Для локального просмотра можно открыть исходный `index.html` или собрать сайт и открыть `dist/index.html`. Для работы без сети нужна вся папка с ресурсами. План и настройки сохраняются в браузере; обмен данными между страницами надёжнее проверять через локальный HTTP-сервер, поскольку поведение хранилища для `file://` зависит от браузера.

## Страницы

- `index.html` — краткое описание, ответ о достижении цели и список разделов.
- `plan.html` — доходы, расходы, накопления, цель, кредит и допущения модели.
- `results.html` — график капитала, бюджет, цель, диапазон результатов и запас средств.
- `compare.html` — экономия, до трёх сохранённых вариантов, таблица, CSV и PNG.
- `inflation.html` — официальный показатель и ручной выбор инфляции.
- `method.html` — формулы, допущения и ограничения.
- `settings.html` — тема, анимации, доступность, экспорт/импорт JSON и сброс.

## Исходники

- `engine.js` — нормализация параметров, единый бюджет, кредит, взнос на цель, симуляция и диапазон сценариев.
- `chart.js` — SVG-график, шкала и подпись цели; `format.js` — суммы, сроки и текст ответа на главной.
- `js/store.js` — сохранение плана, вариантов, настроек и источника инфляции.
- `js/ui.js` — навигация, тема, доступность, уведомления и анимации.
- `js/home.js`, `js/plan.js`, `js/results.js`, `js/compare.js`, `js/inflation.js`, `js/settings.js` — поведение страниц.
- [`js/inflation-data.js`](js/inflation-data.js) — единственная константа официальной инфляции и её метаданные. Для обновления меняйте `MathicalInflation.rate`, период, дату и ссылки в этом файле. Карточка, ИПЦ, кнопка и выбранное значение используют эти данные; ручное значение и значение по умолчанию модели задаются отдельно.
- `css/site.css` — общие стили и адаптация экранов.
- `build.mjs` — сборка; `.github/workflows/pages.yml` — проверки и публикация GitHub Pages.
- `documents/Проверка основы модели.md` — контрольные примеры и границы модели.

Официальный показатель поставляется с сайтом и автоматически не обновляется. Ссылки на первоисточники находятся в файле данных и на странице инфляции. Допустимая инфляция модели — от 0 до 30% в год.

## Решения и сохранение

Допустимые решения: `none` — без изменений; `save` — регулярные расходы ниже на 10%, кредитный платёж не уменьшается. Неизвестное решение в старом сохранении заменяется на `none`. Старые помесячные записи и поля корзины цен игнорируются и не попадают в новый экспорт; из метаданных инфляции остаётся только `source`.

План, варианты и настройки сохраняются одной записью. При ошибке записи форма остаётся открытой с введёнными данными; неудачный импорт не заменяет прежний план. Старые отдельные настройки темы читаются при загрузке.

Режим для слабовидящих включается кнопкой «Аа» в шапке или в настройках. Он увеличивает текст, элементы и контраст, выделяет фокус клавиатуры.

## Сборка и проверки

Нужен Node.js 22 или новее. Установка npm-пакетов не требуется:

```powershell
node --test
node build.mjs
```

Проходят **57 автоматических проверок**: модель — 34, график — 9, хранилище — 8, ответ на главной — 3, инфляция — 1, сборка — 2. Файлы: `engine.test.mjs`, `chart.test.mjs`, `store.test.mjs`, `home.test.mjs`, `inflation.test.mjs`, `build.test.mjs`.

Сборка только создаёт файлы в `dist/`: семь HTML-страниц, CSS, необходимые скрипты, шрифт и лицензию. Хеши ресурсов добавляются только в ссылки собранных страниц. Исходные HTML, CSS и JavaScript не переписываются. `dist/` исключён из Git; для переноса сайта копируйте всю папку, а не один HTML-файл.

При отправке изменений в `main` GitHub Actions запускает тесты, собирает `dist/` и публикует его как артефакт GitHub Pages. Сборка выполняется заново на сервере. Настройка Pages использует источник GitHub Actions; схема описана в [документации GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Границы модели

Результат — учебный расчёт, а не финансовый прогноз. Ставки и сценарии условны; случайные прогоны воспроизводимы и не калиброваны на рынок.

Срок цели задаётся от одного месяца до 50 лет. Взнос учитывает выбранную часть накоплений, инфляцию и доходность. Год достижения общей стоимости цели оценивается по годовым точкам капитала, точный месяц не определяется. Покупка цели автоматически не списывается.

Запас средств использует накопления после разовой траты и обязательные расходы на старте. Действующий кредит рассчитывается равными платежами; комиссии, страховка, переменная ставка и досрочные платежи не учитываются. Долг не прибавляется к капиталу и не вычитается из него.
